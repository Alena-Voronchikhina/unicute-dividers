# UniCute Dividers

Copy decorative Unicode and ASCII dividers to your clipboard.

[Open the live app](https://alena-voronchikhina.github.io/unicute-dividers/)

The app contains 20 dividers and runs without dependencies or a build step.

## Run locally

Clone the repository and open `index.html` in a browser.

## Implementation

- Vanilla HTML, CSS, and JavaScript
- Responsive grid layout
- Clipboard API with a fallback for older browsers
- Native buttons for keyboard navigation
